# Sistema Solar 3D 🌌

Simulador y explorador interactivo del Sistema Solar desarrollado con Three.js y Vite.

## Objetivo

Construir progresivamente un Sistema Solar 3D explorable. Los planetas podrán seleccionarse y abrir un modo planetario de mayor detalle. La primera implementación explorable está centrada en la Tierra y la Luna.

## Estado actual

- Escena WebGL 3D.
- Sol, Tierra y Luna.
- Rotación terrestre.
- Órbita visual de la Luna.
- Selección de la Tierra mediante raycasting.
- Entrada y salida del modo Tierra.
- Cámara orbital con zoom y rotación.
- Interfaz responsive.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre la dirección local indicada por Vite.

## Próximas fases

1. Tierra con texturas geográficas reales.
2. Atmósfera avanzada y capa independiente de nubes.
3. Iluminación día/noche.
4. Luna con textura y relieve visual.
5. Transición animada Sistema Solar → Tierra.
6. Continentes y países seleccionables.
7. Descenso progresivo hacia la superficie.
8. Incorporación del resto de planetas con módulos independientes.
